# v0.1.0-alpha.10

Alpha.10 extracts ordinary Lean `UInt16` and ships Wire16, a big-endian codec with a typed four-byte header and a Go frame reader. Consumers run with Go 1.27.4 and `CGO_ENABLED=0`.

## Install

```sh
elan toolchain install leanprover/lean4:v4.36.0
uv tool install --force --python 3.15 "git+https://github.com/franchb/lean-go.git@v0.1.0-alpha.10"
lean-go --version
lean-go doctor
```

The CLI reports `lean-go 0.1.0a10`. Pin the root Go module with `go get github.com/franchb/lean-go@v0.1.0-alpha.10`. The six standalone demos each have their own Go module. Copy the example from this tag to run it with Go alone. [Installation guide](../cli.md)

## Changes since alpha.9

- Generator v12 represents `UInt16` as Go `uint16`. It supports byte widening and narrowing, OR, and left and right shifts with counts reduced modulo 16. A new scalar in executable code selects IR v14 for a single root or v15 for multiple roots. Older schemas retain their capabilities, including support for an explicit user-defined type named `UInt16`. [Extraction guide](../../README.md#extract-a-module)
- Wire16 adds 11 Lean source theorems covering byte order, round trips and header acceptance and rejection. The native Lean encoder and decoder are compared with extracted Go for every one of the 65,536 words on both supported compilers. The standalone Go consumer also checks all 262,144 valid flag and length combinations. [Wire16 example](../../examples/proofs/wire16)
- `frame.ReadFrame` reads one complete frame from a byte slice and returns its payload and the remaining input. A short header or payload returns `io.ErrUnexpectedEOF` with the original slice. The payload borrows the input buffer. [Go frame reader](../../examples/proofs/wire16/frame)

## Verify

The CLI uses exact compiler identities for Lean 4.36.0 and 4.36.0-rc2. The compatibility corpus has nine successful cases and eight required rejections, including unsupported `UInt16.xor`. [Compiler compatibility](../compiler-compatibility.md)

The separate release walkthrough checks three Clamp claims and 177 Go consumer cases. [Reproduction commands](../release-candidate.md)
