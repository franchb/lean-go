# v0.1.0-alpha.2 — experimental preview

This preview extracts a supported subset of ordinary Lean 4 into standalone Go
packages. Consumers use the Go standard library with `CGO_ENABLED=0`; regeneration
uses Lean 4.35.0, Go 1.27.4 and Python 3.15 through uv.

The initial alpha.1 tag exposed a release-test cleanup issue: Go's default module
cache directories are read-only. The isolated consumer now requests writable
cache directories, allowing its temporary project to be removed after successful
execution. Generated code is unchanged. The alpha.1 tag remains immutable; this
preview uses alpha.2.

Supported forms include pure first-order monomorphic functions, enums and recursive
sums, self recursion, records and updates, local joins, checked reduced-argument
helpers and captured local helpers. UInt32 and UInt64 support literals, addition,
subtraction, multiplication, left shift, equality and unsigned comparisons.

The typed API supplies native scalar types, immutable ADT wrappers, constructors,
record getters, sum destructors and `RunTyped`. The raw API remains available.
Both enforce the same execution limits. IR v6/profile v4 adds exact UInt64 values;
earlier profiles retain their original behavior. The audited normalizer remains
available separately.

This is an experimental API and a tested, trusted extraction pipeline, not a
formally verified compiler. Input Lean source must be trusted for elaboration.
External Lake packages, polymorphism, escaping closures, effects, mutual function
recursion and unrecognized compiler forms are unsupported. Numeric conversions,
division, remainder and other bit operations are outside the current subset.

Local validation includes all 111 Python tests, the full Go suite with native Lean
and regeneration enabled, Go vet, and Windows cross-compilation. UInt64 comparison
covers 953 native/oracle/raw/typed cases, including full-width boundaries. See the
[UInt64 report](../research/extraction-uint64.md) and
[typed API report](../research/extraction-typed-api.md) for details.

The GitHub prerelease record adds links to actual Linux/Windows CI and exact-tag
consumer results. Native Lean validation is Linux-only. Start with the
[walkthrough](../getting-started.md); the project is licensed under
[Apache 2.0](../../LICENSE).
