# v0.1.0-alpha.11

Wire16 can now append frames to a Go byte slice, read a frame from an `io.Reader` and write a frame to an `io.Writer`. Both readers use a generated Lean function to determine how many payload bytes a frame needs. The Go example runs with Go 1.27.4 and `CGO_ENABLED=0`. [Wire16 example](../../examples/proofs/wire16)

## Install

```sh
elan toolchain install leanprover/lean4:v4.36.0
uv tool install --force --python 3.15 "git+https://github.com/franchb/lean-go.git@v0.1.0-alpha.11"
lean-go --version
lean-go doctor
```

The CLI reports `lean-go 0.1.0a11`. Pin the root Go module with `go get github.com/franchb/lean-go@v0.1.0-alpha.11`. Each standalone demo has its own Go module. Copy `examples/proofs/wire16` from the same tag to run the frame examples. [Installation guide](../cli.md)

## Changes since alpha.10

- Generator v13 extracts `UInt16.toUInt32` as a value-preserving Go conversion. An executable widening selects IR and manifest v16 for one root or v17 for multiple roots, with profiles `pure-module/v14` and `pure-module/v15` respectively. Exports using only earlier capabilities keep their schemas. [Extraction guide](../../README.md#extract-a-module)
- Two new Lean theorems specify the exact result of `Wire16.classify`. For a header declaring five payload bytes, two available bytes give `needMore 3` and seven give `complete 5`. Thirteen Wire16 source claims now cover the codec, header and payload completeness. Go tests exercise allocation, slice ownership and I/O. [Source propositions](../../examples/proofs/wire16/proof/Wire16Contract.lean)
- `frame.AppendFrame` derives the header length from the payload, supports overlapping slices and preserves the destination on error. `frame.ReadFrameFrom` reads exactly one frame and returns an owned payload. `frame.WriteFrameTo` validates the whole frame before calling the writer once and returns the number of wire bytes accepted, including on a partial write. [Runnable frame examples](../articles/wire16-frame-roundtrip.md)

## Verify

The six tagged demos check 52 Lean source claims. To upgrade from alpha.10, regenerate the Go package, IR, manifest and proof evidence together in a fresh directory with the matching CLI. The separate release walkthrough checks three Clamp claims and 177 Go consumer cases. [Reproduction commands](../release-candidate.md)

The compatibility corpus has 19 cases across Lean 4.36.0 and 4.36.0-rc2, with ten accepted programs and nine required rejections. Its new cases exercise widening over all 65,536 values and require rejection of the reverse cast `UInt32.toUInt16`. [Compiler compatibility](../compiler-compatibility.md)
