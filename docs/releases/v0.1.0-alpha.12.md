# v0.1.0-alpha.12

Alpha.12 extracts ordinary Lean UInt16 XOR and ships a streaming CRC-16/XMODEM example. Lean 4.36.0 and 4.36.0-rc2 are supported. Deploy the generated code with Go 1.27.4 and `CGO_ENABLED=0`. [CRC-16 example](../../examples/proofs/crc16)

## Install

```sh
elan toolchain install leanprover/lean4:v4.36.0
uv tool install --force --python 3.15 "git+https://github.com/franchb/lean-go.git@v0.1.0-alpha.12"
lean-go --version
lean-go doctor
```

The CLI reports `lean-go 0.1.0a12`. Regenerate the Go package, IR, manifest and proof evidence together when upgrading from alpha.11. [Installation guide](../cli.md)

## Changes since alpha.11

- Generator v14 emits Go `^` for ordinary `a ^^^ b` on two Lean `UInt16` operands. Executable uses select v18 IR for one root and v19 for several. Earlier operations retain their IR schemas. [Extraction guide](../../README.md#extract-a-module)
- Two Lean proofs establish that each byte update agrees with eight reference bit steps for every incoming state and byte, and that any chunk partition gives the same checksum. The Go streaming example returns `0x31C3` for `123456789`. [Proofs and Go example](../../examples/proofs/crc16)
- The compatibility corpus includes 11 accepted programs and nine required rejections. The XOR case compares native Lean and generated Go on 196,608 operand pairs per compiler. [Compatibility harness](../compiler-compatibility.md)

The seven standalone demos exercise 54 Lean source claims. A separate release walkthrough rechecks three Clamp theorems and exercises 177 Go consumer cases. [Reproduction commands](../release-candidate.md)
