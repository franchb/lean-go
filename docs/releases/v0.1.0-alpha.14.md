# v0.1.0-alpha.14

Alpha.14 extracts ordinary Lean byte folds to Go `[]byte`. The CRC-16 stream adapter and checksummed Wire16 reader now use the generated fold. A new proof contract binds the frame's two composition theorems to both generated packages in one evidence file.

## Install

```sh
uv tool install --force --python 3.15 "git+https://github.com/franchb/lean-go.git@v0.1.0-alpha.14"
lean-go --version
lean-go doctor
```

The CLI reports `lean-go 0.1.0a14`. Use Go 1.27.4 and either Lean 4.36.0 (the default) or 4.36.0-rc2. Go consumers run with `CGO_ENABLED=0`. Pair the CLI with examples from the same tag. When upgrading from alpha.13, regenerate the package, IR, manifest and evidence together. [Installation guide](../cli.md)

## Byte folds and streaming CRC-16

Generator v16 accepts a root such as `def update (s : UInt32) (xs : List UInt8) := xs.foldl step s` with a named scalar step. It checks the Lean definition and the compiler's empty and nonempty cases. The typed Go entrypoint borrows its input slice for the call and enforces the same logical limits as the raw list executor. Fold programs use IR v20 for one root and v21 for multiple roots.

The `checksum.Update` API accepts arbitrary chunks and passes up to 256 bytes per generated call. An empty chunk preserves the seed. An error returns the state at the start of the caller's chunk. The frame reader and encoder use this adapter and keep the same wire format. [CRC-16 example](../../examples/proofs/crc16) · [Checksummed frame](../../examples/proofs/checkedframe)

In sequential local benchmark batches on Linux/amd64, the median time per 1 KiB fell from 72.87 µs to 36.47 µs over five runs per version. Both versions measured zero heap allocations. [Benchmark details](../research/generated-go-performance.md)

## Proofs spanning multiple packages

A v2 proof contract accepts named component manifests. The checker proves the declared composition claims once, checks the component sources and generated files, and records their identities together. Changing either frame component's manifest invalidates the tracked evidence. Existing single-manifest contracts continue to use `--manifest`.

From the root of the tagged checkout, run:

```sh
lean-go check-proofs \
  --contract examples/proofs/checkedframe-contract.json \
  --component-manifest wire16 examples/proofs/wire16/wire16/manifest.json \
  --component-manifest crc16 examples/proofs/crc16/crc16/manifest.json \
  --evidence examples/proofs/checkedframe/proof-evidence.json
```

The seven standalone demos contain 54 distinct source claims. The frame adds two more, covering round trips with a suffix and acceptance against an independent CRC model.
