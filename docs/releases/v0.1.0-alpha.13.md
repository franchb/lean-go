# v0.1.0-alpha.13

This preview ships generator v15 and a checksummed Wire16 frame built from two proved components. It supports Lean 4.36.0 (default) and 4.36.0-rc2. Generated consumers run with Go 1.27.4 and `CGO_ENABLED=0`.

## Install

```sh
uv tool install --force --python 3.15 "git+https://github.com/franchb/lean-go.git@v0.1.0-alpha.13"
lean-go --version
lean-go doctor
```

The CLI reports `lean-go 0.1.0a13`. Use examples from the same tag. When upgrading from alpha.12, regenerate the Go package, IR, manifest and proof evidence together. [Installation guide](../cli.md)

## Native scalar execution

Typed roots use native Go integers and booleans when their entire call tree is scalar, acyclic and has no join points. They charge the same logical steps, allocations, frames and slots as the raw executor. Existing IR schemas and Go APIs are unchanged.

On the 1 KiB CRC-16 benchmark, the median of five alternating Linux/amd64 runs fell from 2.071 ms in alpha.12 to 58.33 µs. Heap allocations fell from 58,248 to zero. The report includes the machine, workload and reproduction command. [Benchmark report](../research/generated-go-performance.md)

## Checksummed frames

The encoder covers the four-byte header and payload with CRC-16/XMODEM. A stream reader consumes one frame and leaves the remaining bytes for the next read. Flags 2 and the ASCII payload `123456789` produce the trailer `57 44`.

Two Lean claims establish that decoding a valid encoded frame recovers its contents and preserves any suffix, and that a complete trailer for a parsed header and payload of the declared length is accepted exactly when it matches an independent bit-by-bit CRC. The checker binds both claims to both component manifests. Together with 54 source claims from the seven standalone demos, the release covers 56 distinct claims. Go tests exercise the stream adapter on truncated and corrupted frames. [Proofs and Go example](../../examples/proofs/checkedframe)

To run offline, keep the `checkedframe`, `wire16` and `crc16` directories together under the same parent and run the following from `checkedframe`.

```sh
CGO_ENABLED=0 GOTOOLCHAIN=local GOPROXY=off go test -count=1 ./...
CGO_ENABLED=0 GOTOOLCHAIN=local GOPROXY=off go run .
```
