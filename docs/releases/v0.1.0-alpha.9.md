# v0.1.0-alpha.9

Alpha.9 adds stable Lean 4.36.0 support, checked Go byte-array conversions and a standalone proved header codec. The Python package is `lean-go-tools` version `0.1.0a9`. Generated packages run with Go 1.27.4 and `CGO_ENABLED=0`.

## Install

```sh
elan toolchain install leanprover/lean4:v4.36.0
uv tool install --force --python 3.15 "git+https://github.com/franchb/lean-go.git@v0.1.0-alpha.9"
lean-go --version
lean-go doctor
```

The version command prints `lean-go 0.1.0a9`. Go consumers can pin the root module with `go get github.com/franchb/lean-go@v0.1.0-alpha.9`. The five standalone examples have their own Go modules and can be copied from the tag. [Installation guide](../cli.md)

## Changes since alpha.8

- Stable Lean 4.36.0 is the default. To use rc2, set `LEAN_GO_TOOLCHAIN=4.36.0-rc2` for generation and proof checking. The CLI checks the exact compiler commit through Lean and Lake. The compatibility corpus covers eight successful extractions and seven expected rejections on each compiler, including `withPtrEq`. [Compiler identities and qualification](../compiler-compatibility.md)
- Module generator v11 adds checked `[4]byte` conversions for Lean records containing four `UInt8` fields. For `ByteQuad`, `NewByteQuadFromBytes(wire, limits)` constructs the record and `quad.Bytes()` returns the array. Both follow Lean field declaration order. Check the returned error before using the result. [Byte codec](../../examples/proofs/bytes)
- The header codec parses and writes a version byte, two flag bits and a big-endian 16-bit length. For example, `01 03 12 34` decodes to flags 3 and length 4,660. Nine Lean source theorems specify acceptance, rejection and both round trips. Its raw and typed Go APIs are tested against `encoding/binary` for all 262,144 valid headers. [Header example](../../examples/proofs/header)

## Upgrade and verify

Install the CLI and examples from the same tag. Regenerate the Go package, IR, manifest and proof evidence together into a fresh directory. Alpha.8 used generator v10 and rc2. Alpha.9 records the selected compiler and generator v11 in the corresponding artifacts. The byte adapter uses existing IR schemas. [Proof contracts](../proof-contracts.md)

To reproduce the five tagged examples and their 39 Lean source claims, run the installed-CLI verifiers from the checkout. The release walkthrough records three Clamp claims and 177 Go consumer cases in a separate JSON receipt. The source theorems cover the Lean definitions. The extraction pipeline and Go execution are checked by native comparisons, differential tests and independent consumers. [Verification commands](../release-candidate.md)
