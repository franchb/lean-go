# A copyable Lean-proved clock split in Go

This directory is a complete Go module. Copy it anywhere, then build and run it
with Go **1.27.4**. It has no external Go dependencies, `replace` directives, or
runtime dependency on the lean-go repository. The checked-in package was generated
from ordinary Lean source through the `lean-go` CLI of this checkout; see the
[development installation guide](../../../docs/cli.md#development-checkout).

It is the smallest example of unsigned division and remainder: `Clock.split`
turns a number of seconds into hours, minutes and seconds with `/` and `%` on
`UInt32`, and `Clock.join` recombines them. The assurance is **proved Lean logic
with tested, trusted extraction**; the three source theorems are not an
end-to-end proof of the generated Go program.

## Run with Go alone

From this directory:

```sh
CGO_ENABLED=0 GOTOOLCHAIN=local GOWORK=off GOPROXY=off GOSUMDB=off go test -count=1 ./...
CGO_ENABLED=0 GOTOOLCHAIN=local GOWORK=off GOPROXY=off GOSUMDB=off go run .
```

Expected output:

```text
0 s = 0 h 0 min 0 s = 0 s
3661 s = 1 h 1 min 1 s = 3661 s
86399 s = 23 h 59 min 59 s = 86399 s
4294967295 s = 1193046 h 28 min 15 s = 4294967295 s
```

The Go program calls the generated typed API directly:

```go
import clock "example.com/proved-clock/clock"

time, err := clock.RunSplit(total, clock.DefaultLimits())
hours, ok := time.Hours()
back, err := clock.RunJoin(time, clock.DefaultLimits())
```

## What is included

| File or directory | Purpose |
| --- | --- |
| `source/Clock.lean` | Ordinary Lean implementation: `split` and `join` |
| `proof/ClockContract.lean` | Independently authored expected propositions |
| `proof/ClockProofs.lean` | Proofs by moving to natural numbers and `omega` |
| `proof-contract.json` | Selected roots and theorem-to-expectation mappings |
| `clock/` | Generated Go package and source/output manifest |
| `clock.ir.json` | Producer IR with source and compiler provenance |
| `proof-evidence.json` | Freshly checked source proof evidence bound to generated bytes |
| `main.go`, `main_test.go`, `go.mod` | Standalone consumer, independent checks and local module |

For every `total : UInt32`, the source claims establish:

1. `Clock.join (Clock.split total) = total`: recombining gives the input.
2. `(Clock.split total).minutes < 60`.
3. `(Clock.split total).seconds < 60`.

Lean defines `x / 0 = 0` and `x % 0 = x`; the divisors here are the nonzero
constants 3600 and 60, and the generated Go guards every division anyway. The
Go tests compare both roots with an independent subtraction-only model over
boundary values and 1024 seeded inputs, check the wrapping of `join` outside the
range of `split`, invalid limits and budget exhaustion. These finite tests
exercise the extraction boundary; they are not proofs for all Go executions.

## Regenerate and check proofs

With the CLI of this checkout, Python **3.15**, Go **1.27.4** and Lean/Lake
**4.36.0** (commit `611c117bfaf7b7ae1cfcf246ce6fba31e8f509e9`), run from this
directory:

```sh
lean-go doctor
lean-go generate --source-dir source --module Clock --root Clock.join --root Clock.split --out clock --ir-output clock.ir.json
lean-go check-proofs --contract proof-contract.json --manifest clock/manifest.json --output proof-evidence.json
lean-go check-proofs --contract proof-contract.json --manifest clock/manifest.json --evidence proof-evidence.json
```

The generator refuses differing existing output: after changing source or tools,
generate into new paths and compare. Never edit generated Go by hand. To verify
the complete handoff from the lean-go checkout:

```sh
clock_cli=$(command -v lean-go)
uv run --locked python scripts/check_clock_demo.py --cli "$clock_cli"
```

The verifier regenerates every artifact into a fresh directory, compares the
bytes, rechecks all three proofs and runs the copied tests and executable with
Go alone.
